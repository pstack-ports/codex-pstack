# pstack for Codex

pstack is a Codex plugin for rigorous engineering workflows, reusable skills, and parallel-agent work across investigation, implementation, verification, and shipping. It bundles `deslop`, `control-cli`, and `control-ui`, with skills available through the `pstack:<name>` namespace.

Install pstack from GitHub through the Codex CLI by running `codex plugin marketplace add pstack-ports/codex-pstack` followed by `codex plugin add pstack@codex-pstack` from any directory. Start a new Codex session and invoke a skill such as `$pstack:poteto-mode`.
