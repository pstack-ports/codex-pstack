# pstack for Codex

This project is a Codex adoption of the original pstack plugin.

Install pstack from GitHub through the Codex CLI by running the following commands from any directory. Then start a new Codex session and invoke a skill such as `$pstack:poteto-mode`.

```bash
codex plugin marketplace add pstack-ports/codex-pstack
codex plugin add pstack@codex-pstack
```
